A program that writes the funniest error message a kitchen toaster would show its owner — one line, 120 characters or fewer — to `/output/entry.txt`.

## Entry

> ERROR E04: Toaster is on strike. It demands a window seat and fewer bagels.

## Run

```sh
python3 main.py
```

Writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure stdlib Python 3.13, deterministic output, no trailing newline.
